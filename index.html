Machine Learning

AquaSafe AI

Waterborne Disease Prediction Dashboard

Overview

Developed for the Bugslayer'26 hackathon, AquaSafe AI is a predictive system designed to evaluate water safety. By analyzing physical-chemical parameters, the model assesses water purity and forecasts potential risk indices for waterborne illnesses.

The Problem

Unsafe drinking water leads to significant outbreaks of gastrointestinal diseases. In remote settings, access to immediate biological laboratory testing is limited, necessitating a rapid mathematical assessment of raw water health hazard based on instantly measurable parameters.

The Solution

An AI-powered dashboard that uses machine learning algorithms to map water data (pH, turbidity, temperature) directly to health hazard classifications. It predicts safe/unsafe thresholds and generates warnings immediately upon inputting variables.

Key Features

  • Real-time classification based on user-entered parameters.
  • Risk prediction levels (Low, Medium, Critical Hazard) via supervised ML models.
  • Responsive visual interface to display status indicators using CSS color states.

Challenges & Learnings

A primary challenge was handling non-linear boundaries in water parameters, where temperature combined with slight pH offsets increases risk exponentially. Standard linear classification was insufficient; therefore, we explored tree-based models and polynomial features to properly capture interactions.

Future Improvements

Integrating telemetry hardware (such as pH/temperature sensors linked to a micro-controller) to stream real-time environmental data directly to the web dashboard via an API, removing the need for manual data entry.

Technologies Used

Python Pandas NumPy Scikit-Learn HTML/CSS

Proven accuracy in predicting hazard indices over tested water test-sets.

Healthcare AI Chatbot

AI Assistant for Health Management

Overview

A bilingual (English and Tamil) conversational assistant built during the AI Consortium '26. The chatbot engages in dialog, extracts key symptoms mentioned by the user, and suggests preliminary care advice or recommends medical consultation.

The Problem

Many regional users in Tamil Nadu lack quick access to initial medical translation or basic triage tips. Traditional chatbots are English-only, creating barrier restrictions for vernacular speakers seeking primary guidance.

The Solution

We developed a custom symptom-matching logic operating in both English and Tamil. By utilizing NLP techniques, the bot detects synonyms, processes spelling anomalies, and maps regional descriptions of illness to medical definitions.

Key Features

  • Vernacular support for Tamil and English language input.
  • Keyword tokenization and extraction of symptoms from unstructured user text.
  • Dynamic suggestions for self-care and redirection warnings for severe cases.

Challenges & Learnings

Mapping Tamil text inputs, where phrasing can vary widely and transliterated English-Tamil (Tanglish) is common, was highly complex. Implementing text normalizers and structured dictionary mapping helped refine the accuracy of symptom extraction.

Future Improvements

Deploying transformer models for multilingual intents and expanding the corpus to include a larger database of local health center mapping.

Technologies Used

Python NLTK Bilingual NLP Figma Prototyping

Healthcare Monitoring Dashboard

AI Dashboard for Health Management
(Normal) SPO2 LEVEL 94% (Low Check) BODY TEMPERATURE 98.6 °F (Optimal)

Overview

Created for AI Consortium '26, this health monitoring system acts as an analytics hub. It processes patient biometric data (oxygen levels, heart rate, body temperature) and outputs clean visual graph analyses showing baseline deviations.

The Problem

Medical vitals are frequently captured but rarely visualized in a consolidated, readable manner for patients. Raw biometric streams can look confusing, making anomalies hard to identify without dynamic graphing capabilities.

The Solution

Built an interactive Python dashboard that uses Matplotlib to generate real-time graphs. The interface processes data feeds, checks against clinical safety thresholds, and flags out-of-bound biometrics visually.

Key Features

  • Interactive plotting of vital trends (SpO2, bpm, °C/°F) over custom timeframes.
  • Out-of-range visual alerts highlighting low oxygen (SpO2 < 95%) or fever indicators.
  • Consolidated final report card with averages and automated healthy recommendations.

Challenges & Learnings

Designing custom, beautiful dashboard charts with raw Matplotlib that match a dark web aesthetic required overriding many chart default parameters (e.g., configuring transparent grids, custom neon line colors, and antialiasing properties).

Future Improvements

Converting the Python visualization backend into a full web-compatible system using modern visualization frameworks (like Chart.js or D3.js) for interactive browser-based zoom and tooltips.

Technologies Used

Python NumPy Matplotlib Data Visualization

Immersive Tech

VR Learning Platform

Symposium Technical Paper & Platform Design

Overview

Presented at the 13th National Level Technical Symposium (TEKCLUSTER'25), this research and project concept designs an educational platform based on 3D VR Glasses to increase student interactivity and build practical confidence.

The Problem

Standard text-based schooling often lacks practical visualization, particularly in fields like molecular chemistry, spatial engineering, and anatomy. Students struggle to build intuition, leading to rote memorization.

The Solution

A concept layout and technical roadmap for interactive VR-based modules. The system leverages VR cardboard settings to project 3D assets that students can interact with, enhancing spatial comprehension through active practice.

Key Features

  • Structural design for interactive 3D laboratory rooms.
  • Active-participation scenarios focused on engineering and science models.
  • Technical paper and research validation presented to regional panels.

Challenges & Learnings

Understanding UX requirements for Virtual Reality was critical. The design had to strictly minimize simulator sickness by proposing specific camera movements and frame-rate baselines, teaching me the value of user-centric hardware/software guidelines.

Future Improvements

Developing WebXR-based prototypes that run directly inside mobile web browsers, allowing immediate VR cardboard testing without downloading external native files.

Technologies Used

3D VR Glasses Figma Prototyping Technical Research UX Design
